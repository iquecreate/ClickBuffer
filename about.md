# Click Buffer

An input buffer for Geometry Dash.

Set **Buffer Ticks** (default 5) in the mod settings. If you click up to that many ticks **before** a click would actually work (landing for cube/ball/robot/spider, or touching an orb/ring), the mod holds the click and fires it on the first tick it becomes valid.

Settings: enable toggle, tick window (0 to 30), ground jump buffering, orb/ring buffering, practice/test-mode-only, and a debug log.

Note: this gives an input advantage. Use the *Only In Practice / Test Mode* option if you want to keep it out of normal runs.
